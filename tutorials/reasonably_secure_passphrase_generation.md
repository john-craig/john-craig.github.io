Or: **An Analog Method to Generate Master Passwords**

For this you will need only the following:

\- a set of standard D&D dice

\- a dictionary

\- a pen

\- a notebook

For maximum effort, go find a nice sunny spot in the woods to sit, ideally one with a picnic table.

What we're going to do is chose words randomly from the dictionary and use them your passphrase. This is a bit trickier to accomplish than you might expect. Naturally, we first need to randomly select a page in the dictionary, and then select a word on that page.

First, look at the number of pages in your dictionary containing definitions. 

This should give your a three- or four-digit number. Let's say for example, 651.

Now for each digit, we are going select a die, roll the die, and write down its result.

For the first digit, we select a die with a number of sides at least one greater than the value of the digit. This type of roll will be called an "n+1" roll.

1. If the result of the roll is less then or equal to the value of the digit, write it down
2. If the result of the roll is equal to the value of the digit plus 1, write down 0
3. If the result of the roll is anything else, reroll the die

So, our example number has 6 as the first digit. This means I need chose a die with at least 7 sides. There is no d7 in a standard dice set, so I will go with a d8.

If I get a 1-6 on the d8 roll, I just write that number down. If I get a 7, I write down 0. If I get an 8, I reroll it.

Now, you will be repeating this process for all the following digits working from left to right.  After the first digit, however, you will use the following process for selecting your dice:

* If the previous roll was an "n+1" roll, and the result of that roll was equal to the value of its associated digit, perform an "n+1" roll for the next digit
* Otherwise, use 9 as the value of the next digit for the purposes of selecting the die

Let's suppose we ended up with a 4 as the number we got from the first roll. The first roll *was* an "n+1" roll, but 4 is not equal to 6, obviously, so we'll go with the second case. We use 9 as the value of the next digit, which means we will need a die with at least 10 sides. This gives us a d12, and we continue from there with the rules for evaluation the roll result.

Now, let's say instead we did end up with a 6 on our first roll. We'd want to perform an "n+1" roll for the second roll. So, we would end up selecting a d6, since the second digit is 5 and 5 + 1 = 6. Now, it possible we could roll a 5 on *this* roll too, which means we would also perform a "n+1" roll for the third digit and end up selecting a d4.

One key piece I want to highlight is that you can only end up with an "n+1" roll if the *previous* roll was also an "n+1" roll. Going back to the first part of this example, suppose we only got a 4 for the first roll, and then happened to get exactly a 5 for the second roll. For the third roll, we still use 9 as the value of the digit and end up rolling a d12. Once the chain of "n+1" rolls is broken, it can't be started again.

By the end of this process, you should have your page number.
